Randomizer Projects

This document catalogs independently maintained randomizer projects related to the Ocarina of Time remake.

The purpose of this directory is to make randomizer projects easier to discover, encourage collaboration between developers, and provide a central reference for ongoing randomizer development.

Inclusion in this directory does not imply affiliation, endorsement, compatibility, or verification by this repository or its contributors.

Adding or Updating Projects

Additional projects, tools, research efforts, and related resources may be added to this directory.

When submitting a project, please provide:

- Project name
- Repository or project page
- Brief description of its purpose
- Relevant project category
- Development status, if known

Projects should be linked to their original sources whenever possible. Descriptions should remain factual and avoid implying official affiliation or endorsement.

Maintenance

This directory is community-maintained. Project information may become outdated as projects develop, change ownership, become inactive, or move to new repositories.

Corrections, additions, and updates are welcome through Issues or Pull Requests.
