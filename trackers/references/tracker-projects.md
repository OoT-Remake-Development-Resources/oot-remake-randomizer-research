# OoT Remake Tracker Projects

This document catalogs tracker projects designed for or adapted to the Ocarina of Time remake.

Trackers may provide map-based check tracking, item inventory tracking, automatic progress detection, manual checklists, or combinations of these features.

This directory is divided into map trackers and item-only trackers, with each category further divided according to whether progress tracking is primarily automatic or manual.

## Map Trackers

Trackers that include a map-based representation of locations, collectibles, or player progress.

### Auto Trackers

#### Ocarina Atlas

- **Type:** Map Tracker / Auto Tracker
- **GitHub:** https://github.com/antonioalvromero/Ocarina-Atlas
- **Website:** https://github.com/antonioalvromero/Ocarina-Atlas
- **Description:** Interactive map and collectible tracker featuring live player telemetry, automatic collectible tracking, dungeon maps, location filtering, and second-screen functionality. Supports several recompilation and emulator environments.
- **Status:** Active development

#### OOT Remake Auto Tracker

- **Type:** Map Tracker / Auto Tracker
- **GitHub:** https://github.com/CedricKassen/OOT-Remake-Auto-Tracker
- **Website:** https://github.com/CedricKassen/OOT-Remake-Auto-Tracker
- **Description:** An automatic progress tracker that reads game save data and tracks collectibles, items, songs, masks, bottles, dungeon rewards, and other progress. Includes a map with pins and a spoiler-free mode.
- **Status:** Independent development

#### Hyrule Tracker

- **Type:** Map Tracker / Auto Tracker
- **GitHub:** https://github.com/jv-prado/hyrule-tracker
- **Website:** https://github.com/jv-prado/hyrule-tracker
- **Description:** Desktop companion tracker that reads local save data and updates a checklist, map, counters, and other progress information. Includes a live player map, collectible tracking, game guide, and overlay functionality.
- **Status:** Independent development

#### OOTRR Tracker

- **Type:** Map Tracker / Auto Tracker
- **GitHub:** https://github.com/Br00ty/ootrr_tracker
- **Website:** https://br00ty.github.io/ootrr_tracker/
- **Description:** A browser-based automatic tracker associated with OOTRR.
- **Status:** Independent development

### Manual Trackers

#### OoT Remake Map

- **Type:** Map Tracker / Manual Tracker
- **GitHub:** https://github.com/lucasriondel/oot-remake-map
- **Website:** https://github.com/lucasriondel/oot-remake-map
- **Description:** An interactive map project for the Ocarina of Time remake. Its map data and project have been used as a foundation by other tracker projects.
- **Status:** Independent development

## Adding or Updating Projects

When adding a tracker to this directory, include the following information where possible:

- **Project name**
- **Type:** Map Tracker or Item Only Tracker
- **Tracking method:** Auto Tracker or Manual Tracker
- **GitHub repository**
- **Website:** If the tracker runs in a browser or has an official web interface
- **Description**
- **Development status**

Projects may support both automatic and manual tracking. Classify them according to their primary functionality and document hybrid features in their description.

Prefer original project repositories and official websites over third-party download or distribution sites.
