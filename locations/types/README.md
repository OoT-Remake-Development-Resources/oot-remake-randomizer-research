# Location Types

This directory contains research and documentation relating to the classification of individual item-bearing locations by type.

Location types describe characteristics of checks and may be used to organize research, filter locations, support tracker functionality, or inform randomizer development.

## Scope

Research may include identifying and documenting types of checks such as:

- Chests.
- NPC rewards.
- Pots.
- Crates.
- Freestanding items.
- Collectible rewards.
- Enemy drops.
- Scrub sales or rewards.
- Shop purchases.
- Boss rewards.
- Event rewards.
- Other item-bearing interactions.

These examples are provisional and should not be treated as a finalized classification system.

## Classification Principles

### Consistency

Similar checks should be classified consistently where possible.

### Distinction

Check types should describe meaningful characteristics of a check rather than duplicate area names, logic requirements, or tracker-specific behavior.

### Flexibility

A check may have multiple relevant characteristics. The classification system should not assume every check fits exclusively into a single category.

### Evidence

Classification should be based on observable behavior, reliable documentation, or other supporting evidence when available.

## Relationship to the Location Catalog

Location types provide classification information for individual entries in the master location catalog.

The catalog should remain the primary source for individual location identities. Type documentation should establish the meaning and classification conventions of the categories used.

## Future Development

Location types may eventually support:

- Location filtering.
- Tracker display options.
- Randomizer configuration.
- Data validation.
- Research categorization.
- Automated processing.

The classification system should evolve as the catalog develops and additional requirements become apparent.
